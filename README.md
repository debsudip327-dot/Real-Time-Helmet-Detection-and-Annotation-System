# Real-Time Helmet Detection and Annotation System 🪖

A computer vision project designed to detect motorcycle helmets in real-time using custom YOLOv8 models and OpenCV.

## Features
- Real-time helmet detection using video stream / webcam.
- Automatic bounding box annotation pipeline.
- Lightweight and modular codebase.

## Tech Stack
- **Language:** Python 3.x
- **Framework:** Ultralytics YOLOv8
- **Computer Vision:** OpenCV
